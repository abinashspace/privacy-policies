# Privacy policies

Public GitHub Pages site for the privacy policies of my apps.

Each app has its own folder. The policy for that app is `app-name/index.html`, and it is served at:

https://abinashspace.github.io/privacy-policies/app-name/

Current policies:

- [Cookie Note](https://abinashspace.github.io/privacy-policies/cookie-note/)

To add a policy for a new app, add a folder with an `index.html` and link it from the root `index.html`.
